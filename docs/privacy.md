# 隐私与数据

- 浏览器扩展仅在点击后使用activeTab和scripting读取所选页面，storage保存本地连接设置；host_permissions允许连接127.0.0.1本机服务的不同端口。
- 扩展不读取或上传Cookie、密码、网站认证请求头，不设置遥测或分析服务。
- 服务默认绑定127.0.0.1。数据与随机连接密钥保存在运行目录的data中。
- 网页展示远程封面时，浏览器会向原图片主机发出正常请求；没有下载或永久保存原媒体的承诺。
- 本地导出和备份可能包含私人内容，切勿提交到公开仓库。
- 扩展签名私钥（.pem）、打包扩展（.crx）、SQLite和data目录均应留在个人环境，.gitignore已覆盖这些文件。
- 示例截图使用合成数据。测试夹具中的账号和内容是示例，不是私人数据集。
