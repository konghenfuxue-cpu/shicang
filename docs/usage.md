# 安装与使用

## 启动收藏馆

安装 Python 3.10 或以上版本，并确保 `python --version` 可用。解压项目后，Windows 双击 `Start.cmd`。也可以在项目根目录执行：

```sh
python server.py
```

首次启动生成 `data/collection.sqlite3` 和本地连接密钥。默认尝试8765端口，不可用时依次尝试18765、28765、系统分配端口。以自动打开的页面和终端实际显示地址为准，实际地址也保存在 `data/server-address.txt`。

窗口需要保持运行，关闭窗口即停止服务。端口改变后，请重新复制扩展连接配置。

## 加载扩展与连接

1. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
2. 开启开发者模式，选择“加载已解压的扩展程序”或“加载未打包的扩展程序”。
3. 选择项目内的 `extension` 文件夹，不是项目根目录，也无需“打包扩展程序”。
4. 在本地收藏馆点击“复制扩展连接配置”。
5. 打开目标网站的已登录收藏内容页，点击工具栏中拾藏的图标（也可从拼图菜单找到）。
6. 在新采集面板的密钥栏粘贴，面板会识别地址与密钥，再点击“保存连接设置”。

扩展更新后需要在扩展管理页点击重新加载，并关闭旧面板、从网站页面重新打开。更新前先提交或导出未保存的扫描结果。

## 三个平台的入口

### X

打开 `https://x.com/i/bookmarks`。新版可能跳转到 `https://x.com/i/history`，选中“书签”或“喜欢”；喜欢入口也可能是 `/i/history/likes`。两种标签分别采集，扩展自动分类。

### 抖音

打开 `https://www.douyin.com`，登录后进入“我的”，点击“收藏”或“喜欢”。等列表显示后再打开扩展。只读当前列表的视频/图文链接，不自动展开合集或其他收藏文件夹。作者未出现在卡片中时保持空白。

### 知乎

打开 `https://www.zhihu.com/collections/mine`，点击要导入的收藏夹，进入 `/collection/数字` 地址。不能在“我创建的收藏夹”列表页扫描。每轮读取一页并尝试点击下一页，收藏夹名称自动识别。多个收藏夹需要分别扫描。

“来源收藏夹”保持“未分类”时使用自动名称；手动填写其他名称时使用手填值。

## 扫描、继续与提交

先用2～3轮小样本扫描。X和抖音每轮滚动加载，知乎每轮读取一页。扫描最多300轮。

达到上限后，保持原网站与面板打开，再点击“开始扫描”，从当前位置继续。面板会累计结果并去重。点击停止后，已采集内容仍可提交或导出。

检查预览后点击“检查新增”，再“确认提交”。刷新收藏馆，按平台和来源类型筛选即可查看。不同来源里同一平台的同一内容会合并来源类型，不覆盖个人标签、备注和已看状态。

**关闭或刷新采集面板会丢失未提交数据**，请先提交或导出JSON。当前没有自动保存扫描进度或定时同步。

## 备份与恢复

关闭服务后，把整个 `data` 文件夹复制到安全位置。恢复时关闭服务，先保留当前数据，再将备份的 `data` 放回项目根目录。

JSON导出包含记录字段，可用于检查和迁移来源信息，但当前JSON导入不会恢复标签、备注、已看状态和导入历史。完整恢复应使用data目录。

数据目录和JSON中包含私人收藏；data中还包含本地连接密钥，勿公开上传。升级程序时保留data目录。

## 常见问题

- **启动报10013或端口被占用：** 当前版本自动回退到其他端口。如果全部端口仍不可用，检查系统或安全软件是否限制Python的本机网络访问，不需要直接开放公网端口。
- **预览无法连接：** 检查服务窗口是否仍在运行，重新复制当前地址与密钥；端口可能发生变化。
- **采集0条：** 确认已登录、内容已显示且选中正确标签。页面结构变化时请反馈错误和平台版本，勿上传Cookie。
- **网站总数与采集数量不同：** 总数可能包括未返回或失效条目，也可能是页面未加载、类型未适配或扫描未覆盖全部。保留日志与数量信息再排查，不自动认定已完整。
- **封面不显示：** 远程封面可能失效或禁止跨站加载，链接记录仍然保留。
